# Data Analyzer Dashboard

A minimal Streamlit-based data analyzer dashboard.

## Structure

```
mini-capstone/
├── app.py                  # Main application entry point
├── src/
│   ├── __init__.py
│   ├── data_loader.py      # Data loading logic
│   ├── analyzer.py         # Data analysis functions
│   └── visualizations.py   # Chart creation
├── requirements.txt
└── README.md
```

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
streamlit run app.py
```

Upload a CSV file to analyze and visualize your data.
